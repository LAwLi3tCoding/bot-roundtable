# Native handoff demo / 原生交接演示

Actual Chromium desktop captures at 1280×900, generated by `tests/browser_handoffs.py` with official SDK stdio clients. All identities and work are synthetic DEMO examples; no real Grok/dot/DS Bot account was contacted. No credentials appear in the captured views.

- [中文任务列表](desktop-zh.png) / [English task list](desktop-en.png)
- [中文独立交接结果](native-result-zh.png) / [English handoff result](native-result-en.png)
- [10.4-second browser recording](native-handoffs-demo.webm): 104 actual frames at 10 fps, queued → claimed/progress → both workers completed → Chinese result → another task cancelled. A test drives real MCP calls and Web actions; this is not autonomous real-provider work or a generated animation.

Reproduce locally (requires ffmpeg only for recording):

```bash
HANDOFF_RECORD=1 CHROMIUM_PATH=/usr/bin/chromium PYTHONPATH=. .venv/bin/python tests/browser_handoffs.py
```

Generated files go to ignored `artifacts/handoffs/`. The screenshots in this directory are selected, reviewed public demo assets. UI-language changes do not translate the original English demo messages.

实拍展示任务与独立交接会话，视频状态由真实本机 MCP/HTTP 操作驱动。默认测试不录屏；录制需要 ffmpeg。没有真实产品联通、自动唤醒或 OAuth 成功的暗示。
