# Notes for AI assistants

To set up this project for a person, follow [docs/SETUP_FOR_AI.md](docs/SETUP_FOR_AI.md). It lists the steps only a person can do; stop and ask at each one. Never print or commit secrets.

For code changes: run `ruff check .`, `ruff format --check .`, `mypy` and `python -m unittest discover -s tests` before proposing a change. See [docs/REFERENCE.en.md](docs/REFERENCE.en.md#development-and-contributions).
